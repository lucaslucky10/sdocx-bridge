첫 공개 미리보기 릴리스입니다. 삼성노트의 실제 획과 녹음을 로컬에서 다루고, 개인 손글씨 사전으로 텍스트를 생성하며, Claude에 표준 MCP로 연결합니다.

- 한국어 UI: SDOCX/PDF/글자 사전 업로드, 획 선택·학습, 녹음 추출·재생 준비.
- 텍스트 → 편집 가능한 PDF Ink + native SDOCX 펜 획 + SVG + JSON.
- 한글 자모 조합과 선택적 LaTeX 수식 조판. 없는 글자를 명시적으로 보고.
- MCP 도구 10개, 노트 리소스, 받아쓰기 프롬프트, 읽기 전용 모드.
- 긴 획의 델타 양자화 누적 오차 수정, 생성 후 자동 좌표 왕복 검사.
- 로컬 자동 테스트 26개 통과. 개인 SDOCX 27개 / 112페이지 / 72,431획 처리. 녹음 4개 원본 해시 일치.
