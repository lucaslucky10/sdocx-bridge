v0.1.1 기능별 재점검과 수정 릴리스입니다.

- PDF 재내보내기에서 기존 주석·링크·폼·메타데이터를 보존합니다. 회전된 PDF도 출력 복사본에서 정규화해 쓸 수 있습니다.
- 한 점짜리 펜 획이 SDOCX에서 사라지던 문제를 수정했습니다. 점·등호처럼 떨어진 획도 한 줄 단위로 페이지를 나누며, 원래 획 순서를 유지합니다.
- 모든 파일 생성과 왕복 검증이 성공했을 때만 결과를 공개합니다. 실패한 출력은 불완전한 다운로드로 남지 않습니다.
- 잘못된 PDF·글자 사전·ZIP 경로를 명확히 거부합니다. LaTeX 설치 오류·문법 오류·지원하지 않는 수식 내용도 조용히 누락시키지 않습니다.
- 글자 학습 중복 검사를 수정하고, 웹/MCP 등 여러 프로세스가 같은 사전을 갱신할 때 파일 잠금으로 보호합니다.
- 페이지 전환의 오래된 응답, 반복 재생 타이머와 임시 이미지 URL을 정리했습니다. 여러 파일 중 실패한 파일만 알리고 나머지 가져오기를 계속합니다.
- 완성 파일은 쪽별로 PDF 배경과 손글씨를 함께 미리 볼 수 있습니다. 드래그 선택 영역과 점 획도 표시합니다.
- 로컬 자동 검사 **54개 통과**. MCP 10개 도구·리소스·프롬프트, CLI, 선택적 MathJax를 포함합니다. 실제 브라우저에서 업로드, 드래그 학습, PDF 두 번째 쪽 쓰기와 다운로드를 검사했습니다.

Windows에서는 ZIP을 풀고 `start.cmd`를 실행하세요. 기존 설치도 새 버전의 의존성을 설치하도록 시작 스크립트를 갱신했습니다. 기존 개인 보관함은 그대로 사용할 수 있습니다. 상세 범위는 [검증 보고서](https://github.com/lucaslucky10/sdocx-bridge/blob/main/docs/VALIDATION.md)를 참고하세요.
