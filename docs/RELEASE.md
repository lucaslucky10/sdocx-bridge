v0.2.0: Claude가 삼성노트·PDF 작업을 끝까지 할 수 있게 다시 만든 버전입니다.

- **Claude Desktop 확장(.mcpb)**: 더블클릭 설치, Python 설치 필요 없음(uv가 자동 준비). 설정 화면에서 내 손글씨 파일과 추가 폴더를 고릅니다.
- **파일 바로 열기**: 다운로드·문서·바탕 화면의 .sdocx/.pdf를 이름으로 찾아 엽니다. 원본은 바꾸지 않습니다.
- **기존 삼성노트에 내 글씨 쓰기**: 복사본에 실제 펜 획을 추가합니다. 녹음·이미지·다른 페이지는 그대로 두고 무결성 해시를 다시 계산합니다. 글씨 크기는 그 노트의 내 글씨에 맞춥니다.
- **무료 로컬 받아쓰기**: faster-whisper(large-v3-turbo)로 녹음을 받아쓰고, 문장마다 그때 쓴 필기의 위치를 붙입니다. 필기가 빠진 부분을 찾는 데 씁니다.
- **페이지 보기 개선**: 확대·좌표 격자, 이미지·PDF 배경 포함, 빈 자리와 줄 위치 분석. 쓰기 결과는 확대 미리보기로 돌려줍니다.
- **LaTeX 수식에 Node.js 불필요**: MathJax를 내장 V8(mini-racer)로 실행합니다.
- **웹 화면**: 페이지 위에서 끌어 쓸 위치 지정, 색 선택, 녹음 재생에 맞춰 필기 강조, 받아쓰기 결과에서 필기 없던 문장 표시.

실제로 확인한 것과 확인하지 못한 것은 [검증 보고서](https://github.com/lucaslucky10/sdocx-bridge/blob/main/docs/VALIDATION.md)에 적었습니다. 삼성노트 앱에서 결과 파일 열기, 실제 Claude Desktop에서 확장 설치, Windows 실행은 아직 확인 전입니다.

개인 필기·녹음·글자 사전은 포함하지 않습니다. AGPL-3.0-only. Dietrich(MIT)·MathJax(Apache-2.0) 고지를 보존했습니다.
