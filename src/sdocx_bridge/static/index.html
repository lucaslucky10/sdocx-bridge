노트를 선택하세요

원본을 보존하고 복사본에서 작업합니다.

손글씨를 선택하면 여기에 표시됩니다.
SDOCX 미리보기는 손글씨 획 중심입니다.
획을 누르거나 드래그해 글자를 선택할 수 있습니다.
입력된 텍스트 

            

          

        

      

      

        

          

            
REAL VECTOR INK

            
내 손글씨로 쓰기

            

              글자 사전의 실제 획 좌표로 씁니다. PDF에는 편집 가능한 잉크 주석,
              삼성노트에는 내 펜과 같은 펜 획으로 들어갑니다. 원본은 바뀌지 않습니다.
            

            
            

            
            

              
            

            

              위치를 숫자로 지정 · 고급
              

                
              

              
              
단위는 그 페이지의 좌표입니다. PDF는 pt(72pt = 1인치), 삼성노트는 폭 약 1440입니다.

            

            
          

          

            

              
위치 고르기

              새 노트는 왼쪽 위부터 씁니다.
            

            

              
PDF나 노트를 고르면 그 쪽이 여기에 보입니다.
쓸 자리를 드래그하면 위치와 너비가 정해집니다.

            

            
완성 파일

            

              만들면 PDF · SDOCX · 미리보기를 받을 수 있습니다.
            

          

        

      

      

        

          
CLAUDE · MCP

          
Claude에게 말로 시키세요.

          

            Claude Desktop에 연결하면 Claude가 이 프로그램으로 노트를 열고, 손글씨를
            읽고, 녹음을 받아쓰고, 내 손글씨로 써 줍니다. 별도 API 키나 추가 결제가
            필요 없습니다.
          

          
가장 쉬운 연결 (Windows · macOS)

          
    
            
  1. GitHub 릴리스에서 sdocx-bridge-버전.mcpb를 내려받습니다.
    2. 
            
  2. 파일을 두 번 클릭하거나 Claude Desktop의 설정 → 확장 프로그램에 끌어다 놓고 설치합니다.
    3. 
            
  3. 설정 화면에서 내 손글씨 파일(glyphs.json)을 고릅니다. 작업 폴더는 기본값(문서\Inkbridge)이면 이 화면과 같은 보관함을 씁니다.
    4. 
          

          
확장 설치가 안 되면

          
이 프로그램 폴더의 connect-claude.cmd를 실행하세요. 명령어로는 uv run sdocx-bridge install-claude 입니다.

          
Claude Desktop 설정 파일에 연결 항목을 추가하고 기존 설정은 백업합니다. Claude를 완전히 종료했다가 다시 여세요.

          
이렇게 말해 보세요

          
다운로드 폴더의 회전운동.pdf 3페이지 오른쪽 위에 “토크 = 회전시키는 힘”을 내 손글씨로 작게 써 줘.

            이 화면 자체는 외부로 아무것도 보내지 않습니다. 자세한 내용은 저장소의 docs/CLAUDE.md를 보세요.
